2.Redirect scope#

Every URL that moves needs a 301 redirect to keep its search ranking.

SiteApproachEffort
bmcpc.org.hkStays as the main domain. Keep URLs where possible; redirect only merged pages.Low
bmcpc-info.org.hkWhole domain moves. The 31 最新資訊 articles (/news/detail/{id}) are covered by one pattern rule; the rest are mapped one by one.Medium
bmcpc-shine.org.hkWhole domain moves. Project pages (/pjshare, /dproject, /srproject) use ID patterns.Medium

Reducing page count

  • Recommended. Each facility on the main site is split into 4 pages (簡介 / 認購詳情 / 注意事項 / 收費總表), and these could become one page with tabs.
  • Fewer pages means less translation and less to maintain in 3 languages.
  • Each removed URL gets a 301 to its closest new page.
Why we need Search Console: a crawl only finds pages that are linked. Search Console shows what Google has actually indexed, including old orphan pages, and which URLs bring traffic. Those are the redirects that matter most.

5.Platform#

A fresh WordPress build on our own lean stack: no page builder and no heavy multilingual plugin.

OptionProsConsCost
A. WordPress,
our build stackRecommended
  • Built from our experience running a 3-language WordPress site with AI editing
  • Light, fast pages: no Elementor, no WPML
  • AI can update pages through approved actions; every change saved as a draft for approval
  • GEO built in: structured data, llms.txt
  • Standard WordPress; all code in git and handed over
  • Our modules are newer than mainstream plugins; we maintain them
  • New layouts need a developer
 Base
